Further topics

Optional self-study for those who want to go further. Not examined.

These modules take you beyond the four sessions, into the econometrics you already know from Stata, now done in Python. Each has a short deck, one script that reproduces every number on the slides, the data (offline) and a README. Unzip a module inside your course folder and work through the deck with the script open beside it.

Module What you learn After Time Download
F1 Panel regressions Pooled OLS, person and two-way fixed effects, clustered standard errors, one table; the Python version of reghdfe (random effects in an appendix) Sessions 3–4 about 75 min zip
F2 Binary outcomes Linear probability model, logit, odds ratios, average marginal effects, and the trap of perfect separation Sessions 2 and 4 60–75 min zip
F4 Difference-in-differences and event studies The 2×2 DiD by hand, the same as a two-way fixed-effects regression, an event study with pre-trends, Poisson with fixed effects for counts; on synthetic register-style data where the true effect is known Sessions 3–4, F1 about 75 min zip
F3 Time series Months to quarters, a Phillips curve with Newey–West standard errors, autocorrelation, AR(1), and why these are correlations Session 4 60–75 min zip

F1 and F4 use pyfixest, the package the AI-Econ Lab uses in its own papers. In the VS Code terminal of your course folder, type uv add pyfixest once (F1’s optional appendix also uses uv add linearmodels). These modules use the same tools and conventions as the lab’s published replication packages.

Coming later: causal machine learning. A module on the Modified Causal Forest, a method for estimating how the effect of a programme differs across people, developed with its author, Michael Lechner (University of St. Gallen and guest professor at Örebro University).
