From raw data to results you can trust

The Python part of Programming and Data Management for Economics and Finance. Four sessions on the work behind every empirical result: getting data, checking it, combining it, and producing a table that anyone can rebuild from the raw files.

Set up Python (20 min) Sessions AI rules and tutor prompt

Every number in this course comes from code that someone else can rerun. That is the standard in economics journals, and it is the standard here.

How each session works

Before · a short video (posted during the course) and two or three questions to check yourself.

In class · real code with its real output, a question every 15 minutes, then a lab with help in the room.

After · one exercise, easy to hard, with a self-check script. Solutions here after three days.

Test yourself · a few questions without AI, the way the exam works.

Before the first session

  1. Do the Setup (20 minutes).
  2. Read Kevin Bryan’s tech stack memo, the parts named on the Readings page (20 minutes).

What you need

Your own laptop (Mac or Windows) with the course setup done before the first Python session: Setup. No earlier Python is needed; Part I gives you the programming basics, and session 1 starts with a short bridge from MATLAB to Python.
