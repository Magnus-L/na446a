Sessions

Slides, scripts and exercises, posted before each session.

Session 1. Projects and first steps (Mon 19 Oct)

Goals. After this session you can:

  1. open a Python project in VS Code that has its own environment, and run a script;
  2. organise a project so that someone else can rerun it;
  3. load a dataset in pandas and inspect it: size, first rows, summary statistics.

Before the session: complete the Setup, read the Bryan memo (see Readings) and the AI rules.

Slides: handout, questions without answers (PDF). Full slides, with answers (PDF).

Lab: s1-lab.zip. Unzip it inside your course folder; it contains its own data. Open s1_lab.py and click Run Cell above each step. Steps 1–3 from the slides as one script (under a minute; the last line prints Lab done), then fix an AI-written script: lab01_fix_the_bug.py runs without an error but gives a wrong answer, and you find the bug by testing a case whose answer you know.

Session 2. Working with data (Tue 20 Oct)

Goals. After this session you can:

  1. apply the intake checklist to a variable: type, missing values, range;
  2. fix types and missing values, including sentinel codes such as 999;
  3. create, subset, sort and aggregate variables, and summarise data in a table and a figure.

Before the session: read the Turrell chapter (see Readings), about 20 minutes. Session 2 is the day after session 1, so plan it into the weekend before.

Slides: handout, questions without answers (PDF). The version with answers is posted after the session.

Lab: s2-lab.zip. Unzip it inside your course folder; it contains its own data (auto_messy.csv, titanic.csv). Open s2_lab.py and click Run Cell above each step, filling in the TODOs (about 40 minutes; the last line prints Lab done). Check your work at any time with uv run check_s2.py: all right is 9 of 9 steps right. The AI task: paste your intake output (not the data) into a chatbot, ask what problems it shows, and test two of its claims with one line of code each.

Exercise after the session: a Titanic intake, about 90 minutes, in the same lab folder (titanic_intake.py, self-check uv run check_exercise_s2.py, all right is 8 of 8 tasks right.). Formative, no hand-in; the solution is posted here three days after the session.
