20. Quarterly GDP is 100 in 2023Q1 and 103 in 2024Q1. Which line gives year-on-year growth in per cent for quarterly data?

A. 100 * gdp.pct_change(1) B. 100 * gdp.diff(4) C. gdp.pct_change(12) D. 100 * gdp.pct_change(4)

Answers and why

Show the answers (try first)
  1. C. An absolute path works on one computer only; a path from the project root travels with the project.
  2. A. GPT Tutor, with prompts that safeguard learning, largely removed the drop in exam grades seen with GPT Base.
  3. D. + joins strings; convert with int() first if you want arithmetic.
  4. B. append adds 2 at the end; x[-1] is the last element (2) and the list has 3 elements.
  5. A. A slice includes the start position and stops before the end position: positions 1 and 2.
  6. B. ascending=False puts the largest sales first (Stata: gsort -sales).
  7. C. A new column is computed for every row at once (Stata: gen wage_k = wage/1000).
  8. D. map looks up each code in the dictionary; iloc[1] is the second row (counting from 0), code 3.
  9. D. One non-numeric entry makes the whole column text; replace the code with missing and convert with pd.to_numeric.
  10. C. transform keeps every row and adds the group mean to each (Stata: bysort region: egen), unlike agg, which collapses.
  11. A. nunique counts distinct years within each person; max gives the longest observed history.
  12. B. Their rule A in the Keys chapter: store cleaned data in tables with unique, non-missing keys.
  13. D. Wide to long gives one row per person and year: 3 x 2 = 6 (Stata: reshape long).
  14. C. Two rows repeat an id; only one of them repeats every column. P2 is a real conflict (SE or NO), not a copy: drop_duplicates() would not remove it.
  15. B. The same id stored as 1 and as “1” is not the same key; make the types equal (e.g. astype(int)) before merging.
  16. A. If every output can be rebuilt from raw data by one script, the project is reproducible.
  17. A. One function applied to every element: strip removes spaces, lower changes the case (Swedish letters included).
  18. B. A failed request still returns an answer (an error page); raise_for_status turns it into an error instead of letting bad data flow on.
  19. C. Without return, a function gives back None; computing y inside is not enough.
  20. D. Year on year compares with the same quarter a year earlier: four quarters back.
