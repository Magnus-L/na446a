9. Why does this merge find no matches?

import pandas as pd
a = pd.DataFrame({"pid": [1, 2, 3]})
b = pd.DataFrame({"pid": ["1", "2", "3"], "wage": [100, 110, 90]})
try:
    m = a.merge(b, on="pid", how="left")
    res = "ran"
except ValueError:
    res = "pandas refuses: the key is a number in one table and text in the other"

A. ran B. b has too few rows C. The keys have different names D. pandas refuses: the key is a number in one table and text in the other

10. What does the last line print?

def clean(x):
    return x.strip().lower()

names = [" Lund", "UMEÅ ", "Malmö"]
print([clean(n) for n in names])

A. [‘lund’, ‘umeå’, ‘malmö’] B. An error C. [‘Lund’, ‘Umeå’, ‘Malmö’] D. [’ Lund’, ‘UMEÅ’, ‘Malmö’]

Answers and why

Show the answers (try first)
  1. B. An absolute path works on one computer only; a path from the project root travels with the project.
  2. A, B, D. Raw data are read-only; corrections are made by code that writes to data/processed/.
  3. D. + joins strings; convert with int() first if you want arithmetic.
  4. B. ascending=False puts the largest sales first (Stata: gsort -sales).
  5. A. transform keeps every row and adds the group mean to each (Stata: bysort region: egen), unlike agg, which collapses.
  6. D. Their rule A in the Keys chapter: store cleaned data in tables with unique, non-missing keys.
  7. A, B, C. pandas’ default is how=‘inner’; here how=‘left’ is chosen on purpose, and validate guards the key.
  8. C. Wide to long gives one row per person and year: 3 x 2 = 6 (Stata: reshape long).
  9. D. The same id stored as 1 and as “1” is not the same key; make the types equal (e.g. astype(int)) before merging.
  10. A. One function applied to every element: strip removes spaces, lower changes the case (Swedish letters included).
